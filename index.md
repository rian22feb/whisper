# Whisper

Whisper is a personal dictation app for Windows. It was made for one person's own use and is not sold or distributed.

Whisper turns speech into text on the user's own PC. Speech recognition and grammar clean-up run entirely on that computer, with no cloud service involved.

When the user asks for it, Whisper can add a reminder to the user's own Google Calendar, as a short event with a pop-up alert at the reminder time. It changes or removes that event when the reminder is changed or removed in Whisper.
