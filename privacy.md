# Whisper privacy policy

Last updated: 7 November 2026

Whisper is a personal dictation app that runs on its owner's Windows PC. This policy explains what it does with data.

## Voice and text

Recordings and the text made from them are processed only on the user's own computer. They are never sent to the developer or to any other service. Dictation history, notes and to-dos are stored as files on that computer.

## Google Calendar

If the user connects Google Calendar, Whisper asks for one permission: to view and edit events on the user's calendars (the calendar.events scope). Whisper uses it only to create, update and delete calendar events for reminders that the user has asked to put in the calendar. It does not read, collect or analyse any other events or calendar data.

The sign-in token Google issues is stored only on the user's own computer. No Google user data is sent to the developer or to anyone else, sold, used for advertising, or used to train AI models.

Whisper's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

The user can disconnect at any time in Whisper (Settings > Google Calendar > Disconnect), which deletes the stored token, or remove Whisper's access at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
